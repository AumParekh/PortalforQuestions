  Revision notes
  • Vasicek’s model (CR-10 e, S3). A one-factor Gaussian copula model of time to default that gives high
  percentiles of the portfolio default rate: WCDR(T, X) from PD and a single credit correlation parameter ρ.
  For one loan the Xth loss percentile is WCDR × EAD × LGD.
  • Vasicek and Basel IRB (CR-10 d, S3). Gordy (2003):
  P  for a large portfolio of small loans in a one-factor
  world, the Xth loss percentile is approximately i WCDRi × EADi × LGDi . Regulatory capital for the
  banking book is set from this with T = 1 year and X = 99.9%, sometimes multiplied by a maturity
  adjustment because a loan lasting more than a year may deteriorate without defaulting. See A31 for the IRB
  numbers.
  • Estimating ρ (CR-10 d). Structural models show ρ for two companies is roughly their asset-return correla-
  tion, approximately their equity-return correlation; use the average equity correlation of the obligors, or of
  similar listed companies for private ones.
  • Vasicek’s weakness (CR-10 e). It “incorporates very little tail correlation”; replacing the Gaussian copula
  with another copula can remedy this.
  • CreditRisk+ (CR-10 e, S1). Credit Suisse Financial Products, 1997: “analytic approximations that are well
  established in the insurance industry” (the actuarial approach). With n loans and default probability q, the
  binomial count of defaults is approximated by a Poisson with mean qn when q is small and n large; it still
  holds approximately when PDs differ, provided all are small and q is their average.
  • Default-rate uncertainty creates correlation (CR-10 e). If qn is gamma-distributed (mean µ, standard
  deviation σ), the Poisson becomes a negative binomial. Hull Table 10.4 (µ = 4): the 99.9th percentile of the
  number of defaults is 11 at σ = 0 and 98 at σ = 10. Without uncertainty there is no default correlation and
  the loss distribution is fairly symmetrical; with it, positively skewed.
  • CreditRisk+ by Monte Carlo (CR-10 e). Sample an overall default rate (e.g. from Table 9.6), link each
  category’s rate to it by regression, sample defaults and an LGD per default, total the loss, repeat, read VaR.
  Refinement: default rates are autocorrelated year to year, so model next year’s rate on this year’s.
  • CreditRisk+ in Doumpos (CR-5 f). In contrast to KMV, it does not use the capital structure of the company.
  Losses occur only in the event of bankruptcy; the default frequency is a continuous random variable; defaults
  are small-probability and independent, so the Poisson (mean equal to variance) fits; it calculates default
  events, not ratings; its advantage is the minimum data required.
  • CreditMetrics (CR-10 e, S2). JPMorgan, 1997, built on a rating transition matrix (internal or agency) so it
  captures downgrades as well as defaults. One-year credit VaR by Monte Carlo: simulate every counterparty’s
  end-of-year rating; if not default, revalue all transactions at the horizon using a term structure of credit spreads
  per rating; if default, loss = EAD × (1 − R), with R sampled from an empirical distribution. Upgrades give
  negative losses.

  • CreditMetrics correlation (CR-10 e; CR-12 g). Rating changes are correlated with a Gaussian copula whose
  correlation is typically the equity-return correlation (one-factor CAPM structure for consistency). Thresholds
  come from N −1 of cumulative transition probabilities: an A-rated firm defaults if xA > N −1 (0.9995) =
  3.2905; a B-rated firm if xB > N −1 (0.9619) = 1.7744.
  P
  • CreditMetrics for derivatives (CR-10 e). With no default in year 1, the loss on a trial is i≥j (1 − R)(qi∗ −
  qi )vi : the change in expected default cost from year one onward, using the horizon spread curve’s probabil-
  ities qi∗ .
  • CreditMetrics in Doumpos (CR-5 f). A “mark-to-market model rather than a default mode model”. Inputs:
  issuer rating, transition matrix, recovery rates, yield spreads. Horizon usually one year (up to 10). Criticised
  for homogeneous rating grades and fixed interest rates. Output: the distribution of the change in a loan’s
  value; each loan can carry a different capital requirement. “Not a rating tool, nor a risk pricing model.”
  Three stages: exposure profile, value volatility from upgrades, downgrades and defaults, then correlations to
  aggregate.
  • Same losses, different timing (CR-10 e). On the same assumptions CreditMetrics and CreditRisk+ should
  predict the same long-run loss distribution. A loan downgraded A to BBB, then to B, then defaulting: Cred-
  itRisk+ books nothing until the year-3 default; CreditMetrics books revaluation losses in years 1, 2 and 3,
  which should add up to the same total.
  • Moody’s KMV (CR-5 f, S4). The best-known implementation of Merton’s structural model: asset value and
  volatility are backed out of equity market data. Default point = short-term debt + 12 long-term debt; distance
  to default is mapped to an EDF through an empirical distribution of historical default frequencies, not the
  normal. See A5.
  • Structural versus reduced form (CR-5 f). Structural: default is endogenous, linked to assets and debt
  (Merton, KMV). Reduced form: default is a random event driven by an exogenous Poisson jump process,
  calibrated to bond and credit-derivative prices (Jarrow and Turnbull; Duffie and Singleton). Evidence is
  mixed for structural models; reduced form approaches were found superior in most cases.
  • Hull’s summary (CR-10 e). Vasicek and CreditRisk+ estimate losses from defaults only; the impact of
  downgrades is not considered (except through the maturity adjustment in the regulatory use of Vasicek).
  CreditMetrics differs by counting defaults and downgrades, using a Gaussian copula with a transition matrix.

  Likely distractors
  1. Corrupted: “CreditRisk+ estimates default probabilities from the firm’s capital structure and asset volatility.”
  (sibling swap with KMV)
  True: CreditRisk+ does not use the capital structure; it is an actuarial default-count model. Using the capital
  structure is the KMV/Merton approach.
  2. Corrupted: “CreditMetrics is a default-mode model: a credit loss is recognised only when the counterparty
  defaults.” (sibling swap with CreditRisk+)
  True: CreditMetrics is a mark-to-market model that counts losses from downgrades as well as defaults, and
  upgrades as negative losses.
  3. Corrupted: “Vasicek’s model captures losses from both downgrades and defaults, which is why regulators use
  it for IRB capital.” (sibling swap with CreditMetrics)
  True: Vasicek’s model estimates losses from defaults only; downgrade risk enters the regulatory implementa-
  tion only through the maturity adjustment.
  4. Corrupted: “Moody’s KMV maps distance to default into a default probability with the standard normal dis-
  tribution, using total debt as the default point.” (scope error on both inputs)
  True: KMV uses an empirical distribution of historical default frequencies, and the default point is short-term
  debt plus half of long-term debt.
  5. Corrupted: “In CreditRisk+, uncertainty about the default rate leaves the 99.9% VaR unchanged, because the
  expected number of defaults is the same.” (absolute claim)
  True: Default-rate uncertainty creates default correlation and fattens the tail: with µ = 4 the 99.9th percentile
  rises from 11 defaults (σ = 0) to 98 (σ = 10).
  6. Corrupted: “Because it uses a Gaussian copula, Vasicek’s model generates strong tail dependence between
  defaults.” (polarity flip)
  True: Vasicek’s model incorporates very little tail correlation; another copula is needed to remedy this.
